# علوی‌یار — برنامه‌ی اندروید

نام بسته: `ir.alaviyar.alavi` · نسخه: `1.0.0` · minSdk 21 · targetSdk 36

## ساخت فایل APK با گیت‌هاب
1. یک مخزن (Repository) جدید در گیت‌هاب بساز.
2. **همه‌ی محتوای همین پوشه** (از جمله پوشه‌ی مخفی `.github`) را داخل مخزن آپلود کن. پوشه‌ی `.github` باید در ریشه‌ی مخزن باشد.
3. به تب **Actions** برو ← workflow با نام **build** ← **Run workflow**.
4. بعد از چند دقیقه، در پایین صفحه‌ی همان اجرا، بخش **Artifacts** فایل `alaviyar-1.0.0-apk` را دانلود کن؛ داخلش `app-release.apk` است.
5. APK را روی گوشی نصب کن (اجازه‌ی نصب از منبع ناشناس لازم است).

## نکته‌ها
- فایل‌هایی که دریافت می‌کنی (نمونه سوال، فایل تکالیف) مستقیم از p.alavi.ir در پوشه‌ی `Download/AlaviYar` گوشی ذخیره می‌شوند.
- فایل امضا (`app/alaviyar-release.jks`) داخل پروژه است تا بیلد بدون تنظیم اضافه کار کند. اگر خواستی برنامه را در بازار/مایکت منتشر کنی، کلید اختصاصی خودت را بساز و رمزها را در `app/build.gradle` عوض کن.
- برنامه از WebView سیستم استفاده می‌کند؛ روی گوشی‌های قدیمی بهتر است «Android System WebView» به‌روز باشد.
- ورود شما (کد ملی و گذرواژه) فقط به‌صورت رمزنگاری‌شده روی همین گوشی ذخیره می‌شود و فقط به p.alavi.ir ارسال می‌شود.
